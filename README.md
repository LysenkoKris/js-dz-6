# Домашнее задание 6

- `src/suffixTree.ts` — суффиксное дерево, алгоритм Укконена: построение O(n), поиск подстроки O(m), память O(n)
- `src/palindrome.ts` — самый длинный палиндром через суффиксное дерево, O(n log n)

Установка:

```bash
bun install
```

Запуск (меню, данные вводятся с клавиатуры):

```bash
bun run index.ts
```

Тесты:

```bash
bun test
```
